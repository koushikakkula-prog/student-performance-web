Technical Architecture

How the Prediction System Works

Explore the machine learning pipeline and data processing stages powering the Student Performance Prediction System.

01
1. Enter Student Details

Academic advisors, teachers, or students provide granular metrics covering:

  • Attendance: Percentage of classes attended.
  • Previous & Internal Marks: Prior semester and continuous assessment scores.
  • Study & Sleep Hours: Daily behavioral routines and rest habits.
  • Environmental Factors: Extracurriculars, Internet access, and parental education.
02
2. Data Preprocessing

Raw student parameters are cleansed, encoded, and standardized:

  • Ordinal Encoding: Categorical variables (e.g. Parental Education) are mapped to structured numeric tiers.
  • Feature Scaling: StandardScaler normalizes variances to eliminate feature dominance.
  • Range Clamping: Prevents out-of-boundary anomalies.
03
3. Machine Learning Analysis

The input vector is processed through trained supervised learning models:

  • Random Forest: Aggregates predictions over 150 randomized decision trees to capture non-linear student behavior patterns.
  • Decision Tree & Linear Models: Benchmarked for baseline verification and transparent path analysis.
04
4. Performance Prediction & Grading

Generates exact numerical scores and matches institutional grading scales:

90–100% : Grade O (Outstanding)
80–89% : Grade A+ (Excellent)
70–79% : Grade A (Good)
60–69% : Grade B (Average)
40–59% : Grade C (Needs Work)
<40% : Fail (Below 40%)
05
5. Personalized AI Recommendations

An intelligent heuristic recommendation engine parses specific student vulnerabilities:

  • Attendance Alerts: Immediate remediation for students below the 75% threshold.
  • Study Schedule Tuning: Customized study-hour targets for students underperforming in exams.
  • Sleep & Health Guidance: Adjustments for irregular sleeping routines.
  • Remedial Support: Targeted focus on recurring backlog subjects.
